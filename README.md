# Astral New Tab 星辰新标签页 by rongpengli
![](https://raw.githubusercontent.com/rongpengli/Astral/refs/heads/master/images/marquee-1400x560.png)
[Astral New Tab](https://chromewebstore.google.com/detail/astral-new-tab/mldjngfcllpkobkbfjildlaakkpoaadj) 是一款面向 Chrome 的新标签页扩展，它将常用网站、日期、天气与壁纸整合在一个简洁的新标签页中，让日常浏览更顺手。Astral New Tab 基于 [sakuyaa 开发的 myNewTabWE Firefox 插件](https://github.com/sakuyaa/myNewTabWE) 进行功能扩展，感谢 sakuyaa 为 myNewTabWE Firefox 版所做的贡献<sup>*</sup>。

## 功能亮点

- **Bing 壁纸**：自动更新每日壁纸，也可在最近 1–8 天的壁纸中手动切换；支持 UHD、1920×1080 和 1366×768 分辨率。
- **壁纸下载与自定义**：可手动或自动下载壁纸，并设置下载目录；也可使用自定义图片 URL 或 Data URL。
- **天气**：查看当前天气，可使用浏览器定位或手动选择城市、编辑坐标；天气和浏览器定位均可在选项中管理。
- **公历与农历日期**：方便查看公历、农历、节气及节假日信息。
- **常用网站导航**：自定义分组和网址，自动获取网站图标，也可上传或编辑图标。
- **配置备份与同步**：以 JSON 导入、导出配置；可开启浏览器同步，在支持同步的浏览器设备间上传或恢复导航和设置。自定义壁纸图片等本机数据不会全部上传，详见[隐私权声明](https://raw.githubusercontent.com/rongpengli/Astral/refs/heads/master/Privacy%20Disclaimer)。
- **主页样式定制**：可编辑主页 CSS，调整新标签页的外观。

## 为什么选择 Astral？

- **轻量实用**：常用导航、日期、天气与壁纸集中在新标签页中。
- **灵活可调**：从导航分组到壁纸和主页样式，都可以按自己的习惯设置。
- **配置可带走**：导出 JSON 备份配置，也可使用浏览器同步功能在设备间传递支持同步的数据。

<sup>*</sup> 随着 Astral New Tab 演进，导出的配置中已不再保持与 Firefox 插件的后项兼容。
